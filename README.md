# 周易卜卦 · 手机版

三币起卦的手机端网页应用，把桌面版 `卜卦.html` 改写成手机上顺手可用的版本。

**在线访问：<https://wwx131.github.io/bogua/>**

用手机浏览器打开上面的地址，在浏览器菜单里选择「添加到主屏幕」，即可像 App 一样全屏、离线使用。

## 特点

- **单文件**：`index.html` 内含全部样式、脚本、六十四卦数据与**分方面解读**，无任何外部依赖，断网可用
- **分方面解读**：每卦含 事业 / 财运 / 感情 / 健康 / 人际 / 学业 六个方面的简断与建议，另有关键词与总断
- **问事侧重**：起卦前可选「问什么」，出卦后默认展开对应方面并置顶（选择会记住）
- **手机优先**：卦爻宽度按屏幕宽度自适应，320px 小屏到平板都不折行、不溢出；适配刘海屏安全区
- **底部常驻大按钮**：滚到任何位置都能单手掷币；掷满六次后可随时重新卜卦
- **触摸反馈**：支持震动的机型，掷币与出爻有不同震动节奏
- **3D 硬币翻面**：用 `rotateY` 翻面动画代替原版的跳动动画，手机上更省电顺滑
- **变爻与变卦**：老阴(6)、老阳(9) 标 `×`/`○`，并给出之卦（变卦）的卦名与断辞
- **真随机**：使用 `crypto.getRandomValues()`，无则退回 `Math.random()`
- **无障碍**：尊重系统「减弱动态效果」设置

## 起卦规则

三枚铜钱，正面为 3、反面为 2，三枚之和：

| 和 | 爻 | 标记 |
| --- | --- | --- |
| 6 | 老阴（变爻） | × |
| 7 | 少阳 | |
| 8 | 少阴 | |
| 9 | 老阳（变爻） | ○ |

爻序自下而上（初爻 → 上爻），与《周易》一致。六爻皆静则以本卦卦辞断之，有变爻则兼看之卦。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 应用本体（必需，可单独使用） |
| `manifest.webmanifest`、`icon-192.svg`、`icon-512.svg` | 「添加到主屏幕」的图标与全屏配置 |
| `说明.md` | 更详细的使用说明（含局域网/离线/公网三种用法） |
| `启动手机访问.bat` | 在 Windows 上开一个局域网服务，手机同 Wi-Fi 即可访问 |
| `发布到GitHub.js` | 一键发布/更新本站点（需自备 GitHub 令牌） |

## 本地预览

直接用浏览器打开 `index.html` 即可；也可以双击 `启动手机访问.bat`，在手机同 Wi-Fi 下访问。

## 更新站点

```powershell
$env:GH_TOKEN = "<你的GitHub令牌>"   # 需 repo 权限
node 发布到GitHub.js
```

脚本会读取当前目录下的文件，一次性提交并更新 `main` 分支，然后等待 Pages 构建完成。

## 卦辞数据

六十四卦的上卦、下卦、卦名、拼音、吉凶等级、卦辞与象辞均内嵌于 `index.html`，已校验 64/64 全部命中、无重名、无重复键，与原桌面版逐条一致。

分方面解读（64 卦 × 6 方面，共 768 条简断与建议）与微信小程序版同源，由 `bogua-weapp/tools/` 下的脚本从同一份 `_gen/domains.json` 生成，已校验两端逐字节一致、无重复内容。

> 内容仅作传统文化学习与娱乐参考。健康方面只从传统养生视角谈作息、情绪与饮食节制，不构成任何医疗建议。
