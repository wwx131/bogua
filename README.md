# 周易卜卦 · 手机版

三币起卦的手机端单文件网页应用，含《周易》六十四卦数据、变爻与变卦推断，可离线使用。

**在线访问：** https://wwx131.github.io/bogua/

## 文件
- `index.html` —— 应用本体（样式、脚本、64 卦数据全部内嵌，无外部依赖）
- `manifest.webmanifest`、`icon-192.svg`、`icon-512.svg` —— 添加到主屏幕的图标与全屏配置
- `说明.md` —— 详细使用说明

## 手机使用
用手机浏览器打开上面的在线地址；在浏览器菜单里选择「添加到主屏幕」，即可像 App 一样全屏、离线使用。
